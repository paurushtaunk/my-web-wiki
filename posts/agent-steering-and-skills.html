Agent steering and agent skills are core features

Jul 16, 2026 · by Paurush M Taunk

Agent steering and agent skills are core features that help the Amazon Kiro IDE behave consistently across your projects. When paired with a secure, high-performance Amazon DCV remote desktop environment, these features provide enterprise-grade capabilities for software development.

Key benefits of Agent Steering

Agent steering solves the issue of AI assistants producing inconsistent code patterns by allowing you to define project rules that the agent must follow across all interactions.

  • Persistent context awareness: Steering files capture project conventions, business rules, architecture, and security standards once. You do not need to repeat these instructions in every prompt.
  • Flexible application: You can apply steering at different levels. Global steering rules follow you across all projects, while workspace steering rules remain specific to a single project.
  • Automatic generation: Kiro can automatically analyze your codebase and generate initial steering documents (for example, technical setup steps and structure definitions) for your review.
  • Inclusion modes: You can configure steering files to be always included, triggered based on file matching, or applied manually when specialized guidance is needed.

Key benefits of Agent Skills

Agent skills function like on-demand expertise that the Kiro agent loads only when the task calls for it, keeping the AI's context window focused and fast.

  • Specialized procedures: Skills store specific knowledge for tasks that don't need to be loaded into the workspace 24/7. Examples include database backup procedures, CI/CD deployment routines, or troubleshooting commands.
  • Easy sharing & portability: You can import skills from public repositories (such as a GitHub URL) or export them to share within your team.
  • Progressive context: By loading skills only when needed, Kiro avoids overwhelming the AI model, maintaining fast and accurate code generation.
